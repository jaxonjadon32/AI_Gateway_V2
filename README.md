# AI Agent Gateway Network (AIGN)

AIGN is an Ethereum-based utility token designed to support
on-chain payments for AI tasks and services within the
AI Agent Gateway Network ecosystem.

## Token Information

- **Name:** AI Agent Gateway Network
- **Symbol:** AIGN
- **Blockchain:** Ethereum
- **Maximum Supply:** 100,000,000 AIGN
- **Decimals:** 18

## Description

AIGN provides a blockchain-based payment layer for AI-powered
applications, agents, and services. AI task payments can be
recorded on-chain using unique task identifiers, providing
transparent and verifiable payment processing.
